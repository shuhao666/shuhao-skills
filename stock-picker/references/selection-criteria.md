# 选股标准

## 优质选股（长线价值）

```
资产负债率 < 40%
连续五年 ROE > 20%
连续五年净利润现金含量 > 80%
连续五年毛利率 > 30%
上市 > 3年
```

## 平时选股（日常筛选）

```
涨幅 > -1%
K线实体为阳线
一年内有分红
商誉与净资产比值 < 20%
换手率 > 3%, < 10%
TTM > 0, < 50
60日均线向上
50天平均成交额 > 1亿
收盘价在21日均线之上
上市 > 3年
不在自选股中
```

## 财报季选股

### 标准 A（含技术面）

```
年报净利润 > 0
年报净利润同比增长率 > 0
近半年有分红
商誉与净资产比值 < 20%
换手率 > 3%, < 10%
TTM > 0, < 50
50天平均成交额 > 1亿
60日均线向上
股价在21日均线之上
上市 > 3年
非自选股
```

### 标准 B（纯基本面）

```

商誉与净资产比值 < 20%
换手率 > 3%, < 10%
TTM > 0, < 50

上市 > 3年
非自选股
```

## 短线博弈策略

```
1. 强势板块和题材
2. 股价在5-10元之间
3. 流通股本在4-10亿之间
4. 换手率每日在10%左右
5. 近一个月最少有3次涨停经历
6. K线阳线居多，调整时间不长
7. 没有大机构基金持股
8. 周线多头排列的强势股
```

开仓一只股1成仓，被套不补仓，有题材的做T操作。

## 买入纪律

- 5日线下不买股
- 超跌股需要行业板块有利好
- 要买先缓涨后加速的股票，不买一下子上去的
- 突然暴涨的（1-2天拉上去）坚决不买
- V型上V型下走势太极端的不要碰
- 底部放利空、顶部放利好
- 高开低走量很大的不能碰
