# 板块分析

## 热点判断

- 涨幅榜前5名的板块，涨停股票较多，是真热点
- 热点板块需要一个龙头股票作为旗帜，旗帜不倒，热点不倒
- 一个板块突然成为热点后又缩量冷掉，是低吸机会
- 有1-2个涨停的就是游资的股票

## 热点描述（15秒判断）

```
有涨停的 + 有放量的 + 有跟涨的 + 持续性
```

## 热点切换

指数继续保持上涨势头时，是热点切换的信号。

## 板块轮动顺序

```
1. 券商、互联网金融
2. 游戏、传媒
3. 新能源汽车、锂电池
4. 次新股、超跌股
5. 食品饮料、酿酒
```

## 风向标

| 板块 | 风向标 |
|------|--------|
| 科技 | 中兴通讯 |
| 保险 | 中国人保、中国平安 |
| 银行 | 招商银行 |
| 券商 | 中信证券、中信建投 |
| A股整体 | 中兴通讯 |

## 各板块特性

### 券商信托
- 跳空会低走，开盘就要卖，可适当在尾盘买
- 市场止跌靠券商，而不是银行、保险。券商不止跌，市场不会止跌
- 股票市场好券商好，股票市场不好券商更不好

### 通讯（科技）
- 中兴通讯当天涨3个点以上时，通讯板块往往不会差
- 市场有题材股行情，科技股不会缺席

### 钢铁、煤炭
- 出现在涨幅榜前十名时，往往行情比较差

### 民航机场
- 人民币大升值，航空股关联很大
- 油价下跌，利好航空股

### 黄金、天然气
- 走势与其他板块相反（避险属性）
- 黄金板块往下跳空，开盘就卖

### 酒类
- 年底会涨一波

### 高送转
- 存活时间5-8天
- 挂钩业绩
- 具备条件：每股公积金高 + 每股未分配利润高
- 门槛：主板10送转5+，中小板10送转8+，创业板10送转10+
- 前3月后3月不能有减持计划

## 赚钱效应判断

上证指数与创业板综指：
- 都上涨且比例为1:2 → 有赚钱效应
- 都下跌且比例为1:2 → 有亏钱效应
